# Формат данных материалов и реакций

Файлы `data/materials.json` и `data/reactions.json`. Их читает GDScript (`JSON.parse_string`)
и передаёт в ядро через `SandWorld.load_materials()` и `SandWorld.load_reactions()`.
Числа указываются в СИ, температура — в °C.

## Модель мира

- 1 клетка — кубик со стороной `cell_size_m` (по умолчанию 0.01 м = 1 см). Глубина тоже 1 клетка.
- Пустых клеток нет: «пустота» — это материал `air` со своей температурой и свойствами.
- Порядок материалов в массиве задаёт их id. Индекс 0 всегда `air`. Всего материалов не больше 255.

## materials.json

```json
{
  "version": 1,
  "cell_size_m": 0.01,
  "ambient_temp": 20.0,
  "thermal_time_scale": 1.0,
  "categories": [
    {"id": "powder", "name": "Сыпучие"},
    {"id": "liquid", "name": "Жидкости"},
    {"id": "gas", "name": "Газы"},
    {"id": "solid", "name": "Твёрдые"},
    {"id": "metal", "name": "Металлы"},
    {"id": "nuclear", "name": "Ядерные"},
    {"id": "energy", "name": "Огонь и взрывчатка"},
    {"id": "special", "name": "Особые"}
  ],
  "materials": [ { ...материал... } ]
}
```

`thermal_time_scale` — общий множитель скорости всех тепловых процессов. Он сохраняет реальные
пропорции между материалами, а абсолютное время подгоняет под игру. Значение подбирается
тестом «кастрюля» (см. `docs/api.md`).

## Поля материала

| Поле | Тип | Обяз. | Смысл |
|---|---|---|---|
| `id` | string | да | латиница snake_case, уникальный (`water`, `uranium235`) |
| `name` | string | да | русское название для UI |
| `category` | string | да | id категории; `air` — `special` |
| `state` | string | да | `empty` (только air), `solid`, `powder`, `liquid`, `gas`, `fire` |
| `density` | float | да | кг/м³ при 20 °C |
| `conductivity` | float | да | теплопроводность k, Вт/(м·К) |
| `heat_capacity` | float | да | удельная теплоёмкость c, Дж/(кг·К) |
| `thermal_expansion` | float | нет | объёмный коэффициент β, 1/К. Жидкости и газы: плотность = density/(1+β(T−20)), это нужно для конвекции. Для газов ≈ 1/(T+273) |
| `initial_temp` | float | нет | температура при рисовании, по умолчанию `ambient_temp` (лава 1200, лёд −10, жидкий азот −196) |
| `colors` | string[] | да | 1–4 цвета `#RRGGBB`; клетка получает случайный оттенок из набора |
| `glow` | bool | нет | светится по температуре (чёрное тело выше ~500 °C) |
| `viscosity` | float 0..1 | нет | жидкости: 0 — растекается мгновенно (вода), 1 — почти не течёт (мёд, лава 0.85) |
| `lifetime` | [float, float] | нет | для газов и огня: время жизни в секундах, мин и макс; по истечении → `decay_into` |
| `decay_into` | string | нет | во что превращается по истечении lifetime (по умолчанию `air`) |
| `melt` | object | нет | `{"temp": 1538, "into": "molten_iron", "latent": 247000}` — твёрдое/сыпучее → жидкость |
| `freeze` | object | нет | `{"temp": 0, "into": "ice", "latent": 334000}` — жидкость → твёрдое |
| `boil` | object | нет | `{"temp": 100, "into": "steam", "latent": 2257000}` — жидкость → газ |
| `condense` | object | нет | `{"temp": 100, "into": "water", "latent": 2257000}` — газ → жидкость |
| `ignite` | object | нет | горение: `{"temp": 300, "into": "fire", "burn_time": [1,3], "residue": "ash", "residue_chance": 0.3, "heat": 1.5e7}`, где heat — Дж/кг, выделяемые за время горения |
| `explosive` | object | нет | `{"temp": 200, "radius": 8, "energy": 4.2e6, "into": "smoke"}`, energy — Дж/кг; также срабатывает от огня рядом |
| `acid` | object | нет | для кислот: `{"strength": 0.3, "into": "toxic_gas", "consumed_chance": 0.2}` |
| `acid_resistance` | float 0..1 | нет | 1 — не растворяется (стекло, золото) |
| `nuclear` | object | нет | см. ниже |
| `fixed_temp` | float | нет | клетка держит постоянную температуру (нагреватель, криоплита); такие материалы — `solid` |
| `hidden` | bool | нет | не показывать в палитре (пламя, кориум можно оставить видимым) |
| `desc` | string | нет | короткая подсказка в UI (1 предложение, по-русски) |

Переходы проверяются по порядку: melt, freeze, boil, condense. Пока на скрытую теплоту не
хватило энергии, температура клетки стоит на точке перехода, а энергия копится в фазовом
буфере. Обратный переход возвращает теплоту.

## nuclear

```json
"nuclear": {
  "fissile": 1.0,
  "fast_fission": 0.02,
  "absorb": 0.01,
  "moderate": 0.0,
  "reflect": 0.0,
  "spontaneous": 0.05,
  "decay_heat": 2.0,
  "fission_energy": 3.0,
  "neutrons_per_fission": [2, 3],
  "burnup_into": "spent_fuel",
  "burnup_chance": 0.002,
  "poison_into": null
}
```

Все вероятности относятся к прохождению нейтрона через одну клетку.

| Поле | Смысл |
|---|---|
| `fissile` | вероятность деления медленным (тепловым) нейтроном |
| `fast_fission` | вероятность деления быстрым нейтроном (U-238 ≈ 0.003, U-235 ≈ 0.03) |
| `absorb` | вероятность поглощения без деления (бор ~0.8, кадмий ~0.9, вода ~0.01, ксенон ~0.95) |
| `moderate` | вероятность замедления быстрого нейтрона в тепловой с рассеянием в случайную сторону (вода ~0.3, графит ~0.25, тяжёлая вода ~0.3) |
| `reflect` | вероятность отражения без смены скорости (бериллий ~0.5, графит ~0.15) |
| `spontaneous` | нейтронов в секунду на клетку от спонтанного деления (U-235 и плутоний — малые числа) |
| `decay_heat` | собственный нагрев от распада, Вт на клетку (отработанное топливо — заметно, уран — слабо) |
| `fission_energy` | сколько Джоулей уходит в клетку за одно деление (игровое значение) |
| `burnup_into`, `burnup_chance` | после деления клетка может превратиться в отработанное топливо |
| `poison_into` | U-235 при делении иногда рождает ксенон-135 в соседней пустой клетке (шанс задаётся тут же полем `poison_chance`) |

Нейтронам безразличны и `air`, и все материалы без поля `nuclear`: такие клетки они проходят
насквозь. Выключить это можно, задав `absorb` у бетона, свинца и других.

## reactions.json

```json
{
  "version": 1,
  "reactions": [
    {
      "a": "sodium", "b": "water",
      "chance": 0.3,
      "min_temp": null, "max_temp": null,
      "into_a": "sodium_hydroxide", "into_b": "hydrogen",
      "heat": 4.0e5,
      "explode_radius": 0,
      "desc": "Натрий бурно реагирует с водой"
    }
  ]
}
```

- Реакция проверяется, когда клетка A соседствует с клеткой B (4 соседа).
- `chance` — вероятность в секунду для пары соседей.
- `into_a`/`into_b` — во что превращаются A и B. `null` — клетка не меняется, `"air"` — исчезает.
- `heat` — Джоули, которые реакция выделяет поровну в обе клетки (отрицательное значение — поглощение).
- `explode_radius > 0` — дополнительно взрыв радиусом в клетках.
- Температурные условия проверяются по средней температуре двух клеток.
- Горение, кислота, взрывчатка и фазовые переходы описываются полями материалов, в реакции их не
  дублировать. Реакции нужны для химии пар (натрий + вода, цирконий + пар → водород, термит,
  ртуть + алюминий, вода + лава → камень и пар и т. п.).

## Дополнение v0.1.1

| Поле | Тип | Смысл |
|---|---|---|
| `wind_coupling` | float 0..1 | Насколько воздух увлекает материал. Газы и огонь по умолчанию 1, лёгкие порошки (пепел, снег, опилки, сажа) 0.2–0.6, остальное 0 |
| `gas_alpha` | float 0..1 | Непрозрачность газа при рендере. По умолчанию 0.5, для дыма 0.8, для водорода и гелия 0.25 |
| `fan` | object | `{"dir": [0, -1], "strength": 40}`: клетка дует в направлении dir со скоростью strength клеток/с. Это solid |
| `emit` | object | `{"into": "water", "rate": 20, "temp": null}`: выпускает rate клеток/с в соседние air. temp — температура выпущенного (null — initial_temp материала into). Это solid |
| `drain` | object | `{"rate": 60}`: удаляет соседние не-solid клетки (кроме air), rate клеток/с. Это solid |

Вентиляторы — 4 материала `fan_up`, `fan_down`, `fan_left`, `fan_right`, категория `special`.
Источники: кран воды, лавы, песка, газа (метан), пара. Сток — материал `void`.

| `movable_solid` | bool | Твёрдое тело, которое падает вертикально, если под ним air, газ или более плотная жидкость. Не осыпается по диагонали и не растекается. В жидкости плотнее себя всплывает: лёд и дерево плавают в воде, сталь — в ртути. Задаётся для ice, dry_ice, wood, paraffin, rubber, plastic, aerogel и похожих |
